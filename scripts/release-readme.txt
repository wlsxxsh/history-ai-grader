历史作业批改与学情分析平台 免安装版

请先阅读本压缩包内的《使用说明.md》。

快速开始
1. 先根据火山引擎官方文档申请 API Key：
   - 获取 API Key 并配置：https://www.volcengine.com/docs/82379/1263279
   - 管理 API Key：https://www.volcengine.com/docs/82379/1361424
2. 将 ZIP 解压到可写目录。
3. 双击 start.bat。
4. 如果浏览器没有自动打开，请访问 http://127.0.0.1:3857
5. 进入软件右上角“后台设置”，填写 API Key。
6. 建议先用 Samples/ 目录中的范例资料跑一遍流程。

压缩包内包含
- 使用说明.md
- README.md
- Samples/ 范例资料
- start.bat 与 start.ps1 启动脚本

说明
- 本版本适用于 Windows x64。
- 首次启动后，程序会自动在 data/ 中创建本地运行数据。
- 日志文件保存在 logs/ 目录。
- 范例试题、参考答案和答题卡已放在 Samples/ 目录，并可在软件首页直接打开。
- API Key 需要在软件内自行填写，本发布包不包含任何密钥。
