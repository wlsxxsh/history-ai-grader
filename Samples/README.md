# 范例资料说明

本目录用于放置演示时可直接使用的范例资料。

当前包含：

- `范例-试题.pdf`
- `范例-参考答案.pdf`
- `范例-答题卡.pdf`

## 这些范例有什么用

它们主要用于：

- 初次试用软件时快速看效果
- 向评估人员、领导或同事演示完整流程
- 在不暴露真实学生隐私的前提下进行产品说明

## 推荐演示顺序

建议你这样使用这些范例：

1. 新建一个任务
2. 上传 `范例-试题.pdf`
3. 上传 `范例-参考答案.pdf`
4. 执行 AI 识别并回填题目配置
5. 上传 `范例-答题卡.pdf`
6. 执行答题卡识别
7. 查看批改结果和导出结果
