## 一、软件简介

这是一套面向中学历史作业批改与学情改进场景的软件。它希望帮助教师把最耗时、最重复、最适合结构化处理的环节先交给系统完成，把更重要的判断、复核、讲评和教学决策留给教师自己。

软件不是单一的出分工具，也不是简单地把材料交给模型处理，而是围绕历史作业的真实流程进行设计，已经形成从题目识别、答题卡识别、选择题批阅、主观题批改，到教师复核、学情分析和讲评材料导出的完整链路。对于日常作业、专题训练、阶段测评和项目展示，这套工具都可以提供比较直观、完整的支持。

## 二、六个核心亮点

### 1. 国产智能能力自主可控

软件在智能能力接入上强调分模块配置和自主可控。综合分析、答题卡识别、主观题阅卷等能力可以分别配置接口，便于教师或团队根据效果、速度、成本和稳定性对不同国产模型进行比较、接入和替换，不被单一路线绑定。数据、规则、名单与评分结构也保留在本地环境中，更方便维护和迁移。

### 2. 主观题结构化评分

在主观题部分，软件不是把评分完全交给模型自由发挥，而是先由教师建立结构化评分标准，再由系统在规则框架内执行评分。普通主观题可以按采分点逐点评分，论述题可以围绕“论题、史实、分析、结论”等关键环节进行组织，从而使主观题批改更稳定、更清晰，也更便于教师复核。

### 3. 选择题详细分析与二次解析

软件的选择题部分不只停留在自动判对错和统计得分，还可以从学生维度、题目维度和选项维度生成更细的分析结果。对于低正确率题目，还可以进一步做二次解析，帮助教师把“哪些题错得多”转化为“为什么错、课堂上该怎么讲”的讲评依据。

### 4. 普通型主观题原文挂分和划线展示

这是软件最有辨识度的亮点之一。系统能够把得分依据直接对应到学生原文中的命中片段，通过高亮、挂分或划线等方式展示出来，让教师和学生都能更直观地看到“为什么得分、为什么失分”。批改结果不再只是一个分数，而是变成了可解释、可追踪、可讲评的过程性反馈。

### 5. 论述题要点式批阅

在论述题批改中，软件不是只给出一段笼统总评，而是尽量围绕历史论述题真正关心的关键点来组织评价，例如论题是否明确、史实是否准确、分析是否到位、是否回扣论题、是否形成结论等。这样的处理方式更贴近真实阅卷逻辑，也更有利于后续讲评和训练改进。

### 6. 二次复核与学情诊断

软件在追求批改效率的同时，也为教师保留了最终把关的空间。对于主观题，教师可以进行二次复核、改分和原因留痕；在此基础上，系统还能进一步生成班级层面的采分点命中率、问题分布和薄弱点分析，把单份批改单转化为可用于教学改进的学情信息。

## 四、使用流程

### 第 1 步：申请 API Key

软件中的智能识别、自动分析和批改能力需要通过 API 调用完成。第一次使用前，请先参考火山引擎官方文档申请 API Key：

- [获取 API Key 并配置](https://www.volcengine.com/docs/82379/1263279)
- [管理 API Key](https://www.volcengine.com/docs/82379/1361424)

如果您后续需要完整体验全部自动功能，也可以再根据软件后台设置补充其他所需接口。

### 第 2 步：下载软件

普通用户推荐直接下载 Windows 免安装版。为了方便中国大陆用户，当前提供 GitHub 和蓝奏云两种下载方式：

- [下载 Windows 免安装版 ZIP](https://github.com/wlsxxsh/history-ai-grader/releases/latest/download/history-ai-grader-win-x64.zip)
- [蓝奏云下载](https://wwbom.lanzouu.com/ipVaI3o1w33c)

也可以在这里查看全部版本：

- [Release 页面](https://github.com/wlsxxsh/history-ai-grader/releases/latest)

### 第 3 步：解压并启动

- 将 ZIP 解压到本地一个可写目录
- 优先双击 `点击这里打开软件.bat`
- 浏览器会在服务准备完成后自动打开
- 如果没有自动打开，可手动访问 `http://127.0.0.1:3857`

### 第 4 步：填写后台设置

打开软件右上角“后台设置”，按界面提示填写 API Key、模型名称和接口地址。建议先完成基础设置，再开始后续识别与批改流程。

### 第 5 步：导入范例或正式材料，开始完整流程

第一次使用时，建议优先使用 `Samples/` 目录中的范例资料体验完整流程；熟悉后再导入自己的正式材料。推荐按以下顺序操作：

1. 新建任务
2. 上传试题和参考答案
3. 进行 AI 识别，并检查回填后的题目配置
4. 根据需要补充或微调评分规则
5. 上传学生答题卡
6. 执行答题卡识别，完成姓名、选择题和主观题内容整理
7. 查看选择题批阅结果与统计分析
8. 运行主观题批改，查看结构化评分结果
9. 对需要人工把关的题目进行教师复核
10. 查看班级学情分析结果
11. 导出批改结果和讲评材料

## 六、常见问题

### 1. 我只想试用，需要看源码吗

不需要。普通用户直接下载 ZIP 包即可。

如果 GitHub 下载速度较慢，也可以直接使用蓝奏云链接下载。

### 2. 为什么打开软件后不能直接批改

因为智能识别和批改需要 API Key。请先完成接口申请与后台设置。

### 3. 仓库和 ZIP 包里有没有范例与说明

有。源码仓库和 Release ZIP 包中都包含中文使用说明和范例资料，方便直接演示和上手。

### 4. 范例资料中的姓名是真实信息吗

不是。范例中的姓名均为演示用途的虚构姓名，不涉及真实学生隐私。

### 运行环境

- 当前已验证环境：Windows x64 + Node.js 24.x

### 安装依赖

```bash
npm install
npm --prefix frontend install
npm --prefix server install
npm run prepare:native
```

### 开发运行

```bash
npm run dev:server
npm run dev:frontend
```

前端开发地址：`http://127.0.0.1:5173`  
后端接口地址：`http://127.0.0.1:3857`

### 本地生产方式运行

```bash
npm run build
npm start
```

### 免安装打包

```bash
npm run release:zip:win-x64
```

生成文件位置：`release/history-ai-grader-win-x64.zip`
